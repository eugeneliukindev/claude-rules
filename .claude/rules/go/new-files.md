# Go — Before the First Read

The Go rules beside this file load when a `.go` file is read, the `go-*` skills once one is read
or written. Before writing Go without having read any — a new package in an empty directory, a new
module — read every `.md` file here (`~/.claude/rules/go/`, or `rules/go/` under
`$CLAUDE_CONFIG_DIR`), and invoke `go-packaging` before a new module's first file.
