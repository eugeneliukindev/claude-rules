# Python — Before the First Read

The Python rules beside this file load when a `.py` file is read, the `python-*` skills once one
is read or written. Before writing Python without having read any — a new module in an empty
directory, a new project — read every `.md` file here (`~/.claude/rules/python/`, or `rules/python/`
under `$CLAUDE_CONFIG_DIR`), and invoke `python-project` before a new project's first file.
