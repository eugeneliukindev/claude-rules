# Python - Before the First Read

The Python rules beside this file load when a `.py` file is read, the `python-*` skills once one is read or written.

- **Before writing Python without having read any, read every `.md` file here.** A new module in an empty directory or a new project reads nothing; the files are in `~/.claude/rules/python/`, or `rules/python/` under `$CLAUDE_CONFIG_DIR`.
